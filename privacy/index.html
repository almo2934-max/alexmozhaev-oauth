Privacy Policy

Application HomeTerms of Use

Scope

AlexMoz OS Local Read Capability is a personal-use application for a single owner. It connects to Google services only after the owner grants consent through Google's OAuth flow.

Google data accessed

  • Google Calendar: read-only event information under calendar.events.readonly. The current implementation reads only the owner's primary calendar and projects a minimal set of event fields needed for a bounded morning view.
  • Gmail: metadata under gmail.metadata, such as labels and selected message headers. Gmail message bodies are not accessed.

Purpose of use

Google data is used only to produce a bounded, read-only operational view for the owner, including near-term calendar constraints and limited Gmail metadata triage. The application does not use Google data for advertising, profiling, resale, or unrelated purposes.

Storage and retention

Google-derived Calendar and Gmail records are processed locally and are not mirrored into a persistent mailbox or calendar database by this capability. OAuth credential material is retained only on the owner's authorized Windows device using user-bound protected storage until it is revoked, replaced, or removed.

Sharing and transfer

Google user data is not sold or shared with third parties. This public GitHub Pages site hosts only this policy and related application information; it does not receive OAuth tokens, Calendar records, Gmail metadata, message content, or other Google user data.

Security

The capability is designed with read-only scopes, fixed allowlisted Google API operations, local credential protection, bounded requests, and fail-closed behavior. It does not expose a generic Google API proxy.

User control

The owner can revoke the application's access through Google Account security controls and can remove the local protected credentials from the authorized device.

Contact

Privacy or support questions may be sent using the support contact displayed on the Google OAuth consent screen.
