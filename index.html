AlexMoz OS

Local Read Capability

This page describes a personal-use Google OAuth application used by the owner of AlexMoz OS on an authorized local computer.

Privacy PolicyTerms of Use

What the application does

The application provides a bounded, read-only morning information layer for Google Calendar and Gmail metadata. It is not offered as a public service and is intended for a single owner.

  • Google Calendar permission: calendar.events.readonly.
  • Gmail permission: gmail.metadata.
  • The current Calendar implementation reads the owner's primary calendar only.
  • Gmail message bodies and attachments are not read.
  • The application does not create, edit, send, delete, archive, label, or otherwise mutate Google Calendar or Gmail data.

Data handling

Google-derived data is processed locally on the owner's authorized device for the requested read-only view. OAuth credential material is stored locally using Windows user-bound protected storage. This GitHub Pages site contains only public application information and does not receive Google user data.

Contact

For questions about this application, use the support contact shown on the Google OAuth consent screen.
